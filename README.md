# ✈️ AviaTicketsSearcher API

**Ядро** системы поиска авиабилетов. 
Этот модуль управляет всем процессом: принимает запросы от пользователей (через Telegram Bot), ставит задачи парсерам, хранит историю поиска и возвращает готовые билеты.

## 📌 О проекте

**AviaTicketsSearcher** — это учебно-демонстрационный проект, построенный по принципу **микросервисной архитектуры**. Он состоит из трёх независимых модулей, каждый из которых решает свою задачу:

| Модуль | Назначение | Ссылка на репозиторий |
| :--- | :--- | :--- |
| **API** | REST-интерфейс, бизнес-логика, хранение данных, координация задач | Текущий репозиторий |
| **Parser** | Парсинг внешних авиа-источников (Aviasales, Skyscanner и др.) | [AviaTicketsSearcherParser](https://github.com/haruHishiro/AviaTicketsSearcherParser) |
| **Bot** | Telegram-шлюз: принимает сообщения от пользователей и отправляет им результаты | [AviaTicketsSearcherBot](https://github.com/haruHishiro/AviaTicketsSearcherBot) |

---

## Архитектура системы

Система построена по микросервисному принципу с горизонтальным масштабированием парсеров. Поток данных выглядит так:

### Масштабирование

Правая часть схемы (Parser Core + все парсеры) спроектирована для **горизонтального масштабирования**:

- Каждый парсер — это **независимый микросервис**.
- Для добавления нового сайта достаточно **написать новый парсер** и подключить его к Core.
- Можно запускать несколько экземпляров одного парсера для распараллеливания нагрузки.

## Быстрый старт (локально)

### 1. Клонируй репозиторий
```bash
git clone https://github.com/haruHishiro/AviaTicketsSearcherAPI.git
cd AviaTicketsSearcherAPI
```

2. Настрой базу данных (PostgreSQL)

Создай базу aviasearcher и укажи доступ в application.properties:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/aviasearcher
spring.datasource.username=postgres
spring.datasource.password=your_password
```

3. Запусти приложение

```bash
./mvnw spring-boot:run
```

После запуска API будет доступно по адресу: http://localhost:8080.

---

Запуск через Docker (всей системы целиком)

1. Склонируй все три репозитория в одну папку.
2. В корне создай docker-compose.yml (пример есть в документации).
3. Выполни:

```bash
docker-compose up -d
```

## Структура API модуля

Модуль построен по следующей архитектуре:

```
src/main/java/com/aviasearcher/
├── controller/     # REST-контроллеры (приём запросов)
├── service/        # Бизнес-логика и координация с парсерами
├── repository/     # Работа с БД (Spring Data JPA)
├── model/          # JPA-сущности
├── dto/            # Объекты для передачи данных (запросы/ответы)
└── config/         # Конфигурации (Security, Swagger, и т.д.)
```
